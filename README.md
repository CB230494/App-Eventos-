# Romería Segura — GitHub Pages + Firebase Firestore

Aplicación web estática conservando la navegación y los mapas del proyecto original.

**Instalación:** leer `LEEME_PRIMERO.txt` antes de publicar.

**Base de datos:** Firestore proyecto `romeria-segura`, colecciones `admins`, `reportes`, `reportes_privados`.

Las reglas Firestore se instalan en Firebase Console por separado; subir `firestore.rules` a GitHub no las publica automáticamente.
